# 标记维度任意 N，由同位素替换列表驱动

物种网格与质量简并合并规则按用户提供的同位素替换列表 (元素, 同位素质量数, 目标数) 的元组数 N 动态扩展，不硬编码为 (¹³C, ¹⁵N) 两维。

## Considered Options
- **只 ¹³C 和 ¹⁵N 两维** — 简单，但遇 ²H 等标记需重写数据层。
- **加 ²H 为第三维（硬编码）** — 覆盖 SILAC，但 ³⁴S/¹⁸O 仍要再改。
- **任意 N 维（按输入同位素列表）** — 实现略复杂，质量简并需从"按 ¹³C/¹⁵N 比较"升级为"按总中性质量差比较"。

## Decision
选任意 N 维。理由：项目指令明确"可以有多个 ¹³C 和 ¹⁵N"且开放给其他同位素（"任意元素的天然同位素分布"），按输入列表动态生成维度是唯一不会很快过时的方案。两维场景下"总质量差"合并规则退化为原 README 行为，无回归。

## Consequences
- 同位素核函数（molmass `Formula.spectrum()`）已是任意元素通用，无需改动。
- 物种与简并类的内部表示由 `(k, l)` 升级为长度 N 的元组；所有下游代码（网格生成、合并、报告）须按维度无关的方式实现。
- 报告中的"修饰成功" = (k₁_target, ..., k_N_target) 这一个物种（或其简并类）。
