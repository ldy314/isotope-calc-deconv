# theo 新增"元素表"输入模态，交付 Excel + theo 核心

theo 子命令在 ADR-0003 的四种输入模态（分子式 / 多肽序列 / SMILES / ChemDraw）之外，新增第五种"元素表"输入：三行式（元素 / 同位素种类 / 原子个数），与 Excel Calculator sheet 的输入布局一一对应。Excel 按钮把三行式直接传给 theo。

## Considered Options
- **拼字符串分子式再传** — Excel 三行式拼成带同位素的字符串（如 C120{13C6}H198N28O35）。可行，但字符串语法需自定义解析，且与"同元素多列"的输入天然不匹配（拼串反而丢信息）。
- **元素表直接传（选定）** — theo 接收结构化元素表（list of (element, isotope_or_natural, count)），与 Excel 输入零转换、零歧义，部分标记（同元素多列）天然支持。

## Decision
选元素表输入。理由：Excel 的三行式本身就是结构化数据，转字符串再解析是多余的往返；且同元素多列（如"自然 C×120 + ¹³C×6"）在元素表里是两个条目，字符串语法难以优雅表达。

## Consequences
- 本次交付范围：① Excel 改造（新布局 + "计算前20峰"按钮 + 20 行输出表 + 参数区 z / 质量精度）② theo 最小可运行实现（Python + molmass，支持元素表输入，输出前 20 峰：中性精确质量 / m/z / 相对丰度%，最强峰=100%，质量精度合并容差默认 0.001 Da）。
- 元素表输入同时服务于未来 deconv / quantify 的物种网格生成（同一份结构，天然对接 ADR-0001/0002）。
- theo 完整 CLI（分子式 / SMILES / ChemDraw 解析）后续迭代补齐，本次仅实现元素表路径。
