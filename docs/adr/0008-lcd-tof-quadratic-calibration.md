# 岛津 QTOF `.lcd` 用 TOF 平方标定读质量轴（禁用 openszraw 的线性换算）

2026-09-24 结晶。核心问题：`.lcd`（`QTFL RawData/Centroid Data`）里存的质量轴值 `x` 与真实 m/z 是什么关系？

## 背景

- `openszraw`（开源 clean-room 逆向，`lcd2csv.py` 依赖它）文档与实现对存储值做 **线性**换算 `mz = u64/1e12`。
- 用线性换算读 20260914 那批 `.lcd`，得到主簇 **1442.05 / 1444.34**。与 SPH20291 理论 m/z（z=2→1412.71、z=3→942.14、z=4→706.86）做「电荷 × 加合物 × 单体/二聚体」系统匹配：**0 命中**。
- 由此一度得出**错误结论**：「这批数据不含 SPH20291」——该结论写进了 3 份文档（见下"历史影响"）。

## Decision

**`.lcd` 的质量轴按 TOF 平方关系换算：**

```
m/z = a·x² + c
```

- `x` 仍由 `u64 / 1e12` 从 `Centroid Data` 取得（openszraw 的这一步是对的，错的只是后续换算）。
- **a、c 必须用已知锚点最小二乘标定**，不能写死：
  锚点 = 天然形 / 全标记形在 z=2/3/4 的 M0 峰位（各取 ±0.06 Da 窗内最强点）。
  20260914 批次标定结果 `a = 4.53758732e-04`、`c = -0.44325`，6 锚点残差 **±10 ppm**。
- **未设置标定即报错**（`lcd_io._resolve_calib`），避免静默使用错误质量轴。
- 实现落点：`同位素杂质计算/lcd_io.py`（`set_calibration` / `calibrate_tof` / `read_lcd`）与
  `同位素取代率计算/embedded_engine.py`（自包含版）。**`lcd2csv.py` 的线性换算保留但仅供"看结构"，不得用于定量。**

## 验证

| 项 | 结果 |
|---|---|
| 标定残差（6 锚点最小二乘） | ±10 ppm |
| z=3 天然形 M0 | 实测 942.135 vs 理论 942.1411 ✓ |
| z=3 全标记形 M0 | 实测 944.805 vs 理论 944.8125 ✓ |
| `sp_003.lcd`（`解卷积/再处理2分析/`） | z=3 落 944.805，天然形窗内强度 = **0** → 全标记形 |
| `STD 0.005_001.lcd` | z=3 落 942.135，全标记形窗内强度 = **0** → 天然形 |
| 反向验证 | 若只用单项 `a·x²`（丢掉 c），残差达 ±90–220 ppm，在取代率里会伪装成 **+5% 的假富集** |

## 历史影响（本 ADR 更正的范围）

线性换算造成的错误结论已就地更正：

1. `docs/经验总结-lcd读取与解卷积.md` §2.4、§5 —— 「这批 `.lcd` 测的不是 SPH20291」→ **错**。
2. `解卷积/SPH20291_MS+_解卷积分析.md` §1 —— 「该 `.lcd` 不含 SPH20291」→ **依据不可靠**（原文件已不在树内，无法复验）。
3. `解卷积/再处理2分析/report.md`「已知限制」—— 「本批 `.lcd` 不含 SPH20291，以 `.jdx` 为准」→ **错**。

## Consequences

- 标定参数依赖仪器与采集模式，**换批/换模式需重新标定**；不可硬编码 a、c。
- `.lcd` 的 RT 字段单位是**毫秒**（头部 +4），需 /1000 换成秒；窗口按**秒**表达。
- 标定锚点依赖"目标化合物已知"，因此 `.lcd` 读谱**不是**化合物无关的操作——先有分子式与电荷假设，才能标定。
- 新增/受影响文件：`同位素杂质计算/lcd_io.py`、`同位素取代率计算/embedded_engine.py`；`lcd2csv.py` 加告警注释。
- 结论：**"峰位对不上"时先怀疑读取换算，再怀疑样品身份。**
