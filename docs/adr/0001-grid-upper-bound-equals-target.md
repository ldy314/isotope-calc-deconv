# 物种网格上界 = 目标同位素替换数

物种网格的每个同位素维度 kᵢ 的上界严格等于用户指定的 kᵢ_target，不为过度标记预留余量。

## Considered Options
- **不超过目标（保守）** — 网格 = ∏ᵢ[0, kᵢ_target]。代价小，过度标记会归入最近档位。
- **允许超出目标 Δ** — 网格 = ∏ᵢ[0, kᵢ_target + Δ]。网格体积最多 × (Δ+1)^N，质量简并类激增。
- **自适应** — 先按目标跑，残差高时扩一层。计算量 ×2。

## Decision
选保守方案。理由：肽合成的物理预期是"少标不超标"，过度标记在常规合成中极罕见；为罕见情形扩展网格会显著拉大质量简并类、降低 NNLS 数值稳定性。若未来实测遇到过度标记导致系统性偏差，新建 ADR 重新评估，而不是就地修改网格生成器。
