## 4. 关键技术点

1. **CDXML 容错解析**：源文件第 6130 行附近含非法 UTF-8 字节（ChemDraw 计算属性字段的乱码），需用 `errors="replace"` 并用正则替换 XML 声明与 DOCTYPE 后再解析。
2. **骨架一致性**：抹去同位素后 canonical SMILES 完全一致，证明两图确实是同一分子。
3. **残基识别**：基于酰胺键 C(=O)-N 找 α-碳，再用广度优先搜索隔离侧链；青霉胺、Api 等非常规氨基酸被正确识别为“非天然”但位置可定。
4. **修饰位置**：用 SMARTS 在完整分子上验证：7-Me-Trp、C18 二酸、双 AEEA、γ-Glu、一级酰胺/游离羧酸等。
